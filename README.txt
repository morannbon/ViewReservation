# ViewReservation v1.8.2

ViewReservation は、TVTest 用の軽量な視聴予約・録画予約プラグインです。
TVTest の EPG 番組表に加え、設定で有効にした標準パネルからも番組を選んで予約できます。

## 主な機能

- EPG 番組表から視聴予約 / 録画予約
- 予約開始30秒前から切替準備
- 録画中は現在の録画を優先し、録画終了後に次の視聴 / 録画予約へ切替
- 地上波 / BS / CS の切替
- 現在番組のダブルクリックによるチャンネル切替
- パネルで各局の現在番組と放送時間を表示
- `▽` で選んだ局だけ6時間後までの番組を表示
- 現在番組 / 未来番組の右クリックから視聴予約 / 録画予約
- `▶` で視聴予約、`●` で録画予約を表示
- 録画予約どうしが重なる場合は、既存の録画予約を維持して新しい録画予約を追加しない
- 見切れる番組タイトルは、マウスを少し留めた行だけ右から左へ流して表示
- パネルの背景は TVTest のテーマに追従
- パネル機能は初期OFF
- WebView / .NET などの追加ランタイム不要
- x64 / x86 両対応

## 動作環境

- Windows 10 / 11
- TVTest 0.10.0 以降
- BonDriver を利用する TVTest 環境
- Visual Studio 2022（ソースからビルドする場合）

## インストール

1. TVTest を終了します。
2. 使用している TVTest に合わせて x64 または x86 の `ViewReservation.tvtp` を TVTest の `Plugins` フォルダへ配置します。
3. TVTest を起動します。
4. EPG 番組表で番組を右クリックし、`視聴予約` または `録画予約` を選びます。

## パネルを使う

パネル機能は初期状態ではOFFです。

1. TVTest のプラグイン設定から `ViewReservation` を開きます。
2. `パネルを使用する` をONにします。
3. TVTest を再起動します。
4. TVTest のパネルに `ViewReservation` が追加されます。

OFFの場合、パネルは登録されず、EPG 番組表からの予約機能だけが動作します。

## パネル操作

- `地上波` / `BS` / `CS` で放送波を切り替えます。
- 各局には現在放送中の番組タイトルと放送時間が表示されます。
- 現在番組をダブルクリックすると、その局へ切り替えます。
- 右端の `▽` を押すと、その局だけ現在時刻から6時間後までの番組を表示します。`△` で閉じます。
- 現在番組または未来番組を右クリックすると、`視聴予約` / `録画予約` を選べます。
- 予約済み番組は `▶` が視聴予約、`●` が録画予約です。
- 予約済み番組は右クリックから予約種別の変更または解除ができます。
- 各放送波の局順は TVTest / BonDriver のチャンネル定義順です。

## 予約時の動作

予約は開始時刻の30秒前から切替準備を始めます。

録画中に次の視聴予約または録画予約の時刻が近づいた場合、現在の録画を途中で止めません。録画終了を待ち、終了後に次の予約先へ切り替えます。

録画予約どうしの放送時間が重なる場合は、既存の録画予約を維持し、新しい録画予約は追加しません。終了時刻と次の開始時刻が同じだけの場合は重複として扱いません。

## 設定ファイル

予約情報とパネルのON / OFFは `ViewReservation.ini` に保存されます。

## 更新

更新時は TVTest を終了してから、`Plugins` フォルダの `ViewReservation.tvtp` を新しいファイルへ置き換えてください。
既存の `ViewReservation.ini` を残せば、予約情報とパネル設定を引き継げます。

## ソースからビルド

1. `ViewReservation.sln` を Visual Studio 2022 で開きます。
2. `Release | x64` または `Release | Win32` を選択します。
3. ビルドします。
4. `bin` 配下に生成された `ViewReservation.tvtp` を TVTest の `Plugins` フォルダへ配置します。
