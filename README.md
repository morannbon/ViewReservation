# ViewReservation v1.8.6

## v1.8.6 の更新内容

- TVTest標準パネルにザッピングと終了タイマーを追加しました。ザッピング間隔は30～180秒から選択できます。終了タイマーは1～6時間から選択できます。
- TVTestで有効にした局だけを一覧に表示するようにしました。現在視聴中の局を色分けして一覧の中央付近へ表示します。ザッピング中は別の色で表示します。
- パネル上部に番組一覧の更新ボタンとTVTest終了ボタンを追加しました。両ボタンは固定サイズです。放送波ボタンは残りの横幅に合わせて伸縮します。
- 局一覧のスクロール表示を改善しました。パネルの幅や高さを変更しても上下端に不自然な空白や表示の欠けが残らないように修正しました。番組一覧の更新後も表示位置を維持します。
- 更新ボタンと電源ボタンを小さなアイコンへ変更しました。局一覧の開閉マークも小さな山形に統一しました。
- 予約情報の読込と保存の安定性を改善しました。

ViewReservationはTVTest用の視聴予約・録画予約プラグインです。
TVTestのEPG番組表と標準パネルから視聴予約や録画予約ができます。標準パネルは設定で有効にできます。

## 主な機能

- EPG 番組表から視聴予約 / 録画予約
- 予約開始30秒前から切替準備
- 録画中は現在の録画を優先して録画終了後に次の視聴 / 録画予約へ切替
- 地上波 / BS / CS / CATV の切替（CATVは対応環境でのみ表示）
- TVTestで有効にしているチャンネルだけをパネルへ表示
- 現在番組をダブルクリックしてチャンネル切替
- パネルで各局の現在番組と放送時間を表示
- 各局の下向きの開閉マークで6時間後までの番組を表示。上向きの開閉マークで閉じる
- 30 / 60 / 90 / 120 / 180秒から選べるザッピング
- パネル右上で番組一覧を更新する更新ボタン
- パネル右上からTVTestを終了する電源ボタン
- 1～6時間から選べるTVTest終了タイマー
- 現在番組 / 未来番組の右クリックから視聴予約 / 録画予約
- `▶` は視聴予約を表示。`●` は録画予約を表示
- 録画予約どうしが重なる場合は既存の録画予約を維持して新しい録画予約を追加しない
- 見切れる番組タイトルはマウスを少し留めた行だけ右から左へ流して表示
- パネルの背景と操作部の基本色は TVTest のパネル配色に合わせて表示
- パネル機能は初期OFF
- WebView / .NET などの追加ランタイム不要
- x64 / x86 両対応

## 動作環境

- Windows 10 / 11
- TVTest 0.10.0 以降
- BonDriver を利用する TVTest 環境
- Visual Studio 2022（ソースからビルドする場合）

## インストール

1. TVTest を終了します。
2. GitHub Releasesから使用中のTVTestと同じビット数のビルド済みZIPを取得して展開します。ソース版を利用する場合は「ソースからビルド」の手順でプラグインを生成します。`ViewReservation.tvtp` をTVTestの `Plugins` フォルダへ配置します。
3. TVTest を起動します。
4. EPG番組表で番組を右クリックして `視聴予約` または `録画予約` を選びます。

## パネルを使う

パネル機能は初期状態ではOFFです。

1. TVTest のプラグイン設定から `ViewReservation` を開きます。
2. `パネルを使用する` をONにします。
3. TVTest を再起動します。
4. TVTest のパネルに `ViewReservation` が追加されます。

OFFの場合はパネルを表示せずEPG番組表からの予約機能だけが動作します。

## パネル操作

- `地上波` / `BS` / `CS` で放送波を切り替えます。CATV対応環境では `CATV` も表示されます。
- 右上の更新ボタンを押すと表示中の番組一覧を更新します。
- 右上の電源ボタンを押すとTVTestを通常終了します。
- TVTestで有効にしている局だけを表示します。同じ放送サービスが複数の受信経路にある場合は1局として表示します。
- 各局には現在放送中の番組タイトルと放送時間が表示されます。
- 現在番組をダブルクリックするとその局へ切り替えます。現在視聴中の局は色分けされて一覧の中央付近へ移動します。
- 各局の右端にある下向きのマークを押すと6時間後までの番組を表示します。上向きのマークで閉じます。
- 現在番組または未来番組を右クリックして `視聴予約` / `録画予約` を選べます。
- 予約済み番組は `▶` が視聴予約です。`●` が録画予約です。
- 予約済み番組は右クリックから予約種別の変更または解除ができます。
- 各放送波の局順は TVTest / BonDriver のチャンネル定義順です。
- ザッピング間隔は設定画面で30 / 60 / 90 / 120 / 180秒から選べます。パネルの `開始` を押すと設定時間後に最初の切替を行います。
- ザッピング中は現在の局を通常視聴とは別の色で表示します。局をダブルクリックするとザッピングを停止して選んだ局へ切り替えます。放送波ボタンを切り替えただけでは停止しません。
- `終了` は1～6時間から選択します。`開始` でTVTestの終了タイマーを開始できます。録画中に時間になった場合は録画終了後にTVTestを終了します。
- 録画中はザッピングによるチャンネル切替を行いません。

## 予約時の動作

予約は開始時刻の30秒前から切替準備を始めます。

録画中に次の視聴予約または録画予約の時刻が近づいても現在の録画を途中で止めません。録画終了を待って次の予約先へ切り替えます。

録画予約どうしの放送時間が重なる場合は既存の録画予約を維持します。新しい録画予約は追加しません。終了時刻と次の開始時刻が同じだけの場合は重複として扱いません。

## 設定ファイル

予約情報・パネルのON / OFF・ザッピング間隔・終了タイマーの時間選択は `ViewReservation.ini` に保存されます。

## 更新

更新する場合はTVTestを終了して `Plugins` フォルダの `ViewReservation.tvtp` を新しいファイルへ置き換えてください。
既存の `ViewReservation.ini` を残すと予約情報とパネル設定を引き継げます。

## ソースからビルド

1. 配布されたソースZIPを展開して `ViewReservation.sln` をVisual Studio 2022で開きます。
2. `Release | x64` または `Release | Win32` を選択します。
3. ビルドします。
4. `bin` 配下に生成された `ViewReservation.tvtp` を TVTest の `Plugins` フォルダへ配置します。
