ViewReservation v1.8.3

概要
----
ViewReservation は TVTest 用の軽量な視聴予約・録画予約プラグインです。
EPG 番組表と、設定で有効にした TVTest 標準パネルから予約できます。

パネル
------
パネル機能は初期状態ではOFFです。
TVTest のプラグイン設定から ViewReservation を開き、「パネルを使用する」をONにしてTVTestを再起動すると、パネルに ViewReservation が追加されます。

地上波 / BS / CS を切り替えると、各局の現在番組と放送時間を確認できます。
CATV対応環境では CATV も表示されます。
現在番組をダブルクリックすると、その局へ切り替えます。

各局の右端にある「▽」を押すと、その局だけ現在時刻から6時間後までの番組を表示します。「△」で閉じます。
現在番組または未来番組を右クリックすると、「視聴予約」「録画予約」を選べます。
予約済み番組は「▶」が視聴予約、「●」が録画予約です。
予約済み番組は右クリックから予約種別の変更または解除ができます。

見切れる番組タイトルは、マウスを少し留めた行だけ右から左へ流して表示します。
パネル背景は TVTest のテーマに追従します。

EPG番組表
---------
番組を右クリックし、「視聴予約」または「録画予約」を選択します。

予約時の動作
------------
予約は開始時刻の30秒前から切替準備を始めます。
録画中は現在の録画を途中で止めず、録画終了後に次の視聴予約または録画予約へ切り替えます。

録画予約どうしの放送時間が重なる場合は、既存の録画予約を維持し、新しい録画予約は追加しません。
終了時刻と次の開始時刻が同じだけの場合は重複として扱いません。

設定保存
--------
予約情報とパネルのON / OFFは ViewReservation.ini に保存されます。

ビルド
------
ViewReservation.sln を Visual Studio 2022 で開き、Release | x64 または Release | Win32 でビルドします。

表示
----
時刻は番組名とは別の色で表示します。ウィンドウ幅を変更した場合も、番組一覧が崩れないように表示します。
