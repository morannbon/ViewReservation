ViewReservation v1.8.0 ドキュメント
====================================

概要
----
ViewReservation は TVTest 用の視聴予約 / 録画予約プラグインです。
TVTest の EPG 番組表から予約を登録し、指定時刻に自動でチャンネルを切り替えます。

対応環境
--------
- Windows 10 / 11
- TVTest 0.10.0 以降
- x64 / x86
- BonDriver ベースのチューナー環境

インストール
------------
1. 使用している TVTest に合わせて x64 または x86 の ViewReservation.tvtp を選びます。
2. TVTest の Plugins フォルダへ配置します。
3. TVTest を起動します。

使い方
------
1. TVTest の EPG 番組表を開きます。
2. 番組を右クリックします。
3. 視聴予約 または 録画予約 を選択します。
4. 予約時刻になると自動でチャンネルが切り替わります。

保存ファイル
------------
予約情報は ViewReservation.ini に保存されます。

注意
----
TVTest 本体、BonDriver、B25 関連ファイルは同梱していません。
