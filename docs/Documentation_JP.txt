ViewReservation v1.8.6

概要
----
ViewReservationはTVTest用の視聴予約・録画予約プラグインです。
EPG番組表と設定で有効にしたTVTest標準パネルから予約できます。

パネル
------
パネル機能は初期状態ではOFFです。
TVTestのプラグイン設定からViewReservationを開きます。「パネルを使用する」をONにしてTVTestを再起動するとパネルにViewReservationが追加されます。

地上波 / BS / CS を切り替えると各局の現在番組と放送時間を確認できます。
右上の更新ボタンで番組一覧を更新できます。電源ボタンではTVTestを通常終了できます。放送波ボタンは横幅に合わせて伸縮します。更新ボタンと電源ボタンは固定サイズです。アイコンは小さく控えめに表示します。
TVTestで有効にしている局だけを表示します。同じ放送サービスが複数の受信経路にある場合は1局として表示します。
地上波・BS・CSに分類されない局がある場合はCATV欄も表示されます。CATV経由の再送信局でも地上波・BS・CSとして識別できる局は各欄に表示されます。
現在番組をダブルクリックするとその局へ切り替えます。現在視聴中の局は色分けされて一覧の中央付近へ移動します。

各局の右端にある下向きのマークを押すとその局だけ現在時刻から6時間後までの番組を表示します。上向きのマークで閉じます。背景色が変わっても開閉表示を見分けられます。
現在番組または未来番組を右クリックして「視聴予約」「録画予約」を選べます。
予約済み番組は「▶」が視聴予約です。「●」が録画予約です。
予約済み番組は右クリックから予約種別の変更または解除ができます。

見切れる番組タイトルはマウスを少し留めた行だけ右から左へ流して表示します。
パネル背景と操作部の基本色は TVTest のパネル配色に合わせて表示します。

ザッピング間隔は設定画面で30 / 60 / 90 / 120 / 180秒から選べます。パネルの「開始」を押すと設定時間後に最初の切替を行います。
ザッピング中は現在の局を通常視聴とは別の色で表示します。局をダブルクリックするとザッピングを停止して選局します。放送波ボタンを切り替えただけでは停止しません。
録画中はザッピングによるチャンネル切替を行いません。

終了タイマーは1～6時間から選べます。録画中に時間になった場合は録画終了後にTVTestを終了します。
パネル下部はザッピングを左側に配置します。終了タイマーは右側です。1段で表示します。狭い幅では説明ラベルを省略します。

EPG番組表
---------
番組を右クリックして「視聴予約」または「録画予約」を選択します。

予約時の動作
------------
予約は開始時刻の30秒前から切替準備を始めます。
録画中は現在の録画を途中で止めません。録画終了後に次の視聴予約または録画予約へ切り替えます。

録画予約どうしの放送時間が重なる場合は既存の録画予約を維持します。新しい録画予約は追加しません。
終了時刻と次の開始時刻が同じだけの場合は重複として扱いません。

設定保存
--------
予約情報・パネルのON / OFF・ザッピング間隔・終了タイマーの時間選択は ViewReservation.ini に保存されます。

ビルド
------
ソースZIPを展開してViewReservation.slnをVisual Studio 2022で開きます。Release | x64 または Release | Win32 でビルドします。

表示
----
時刻は番組名とは別の色で表示します。ウィンドウ幅を変更した場合も番組一覧が崩れないように表示します。

局一覧は表示領域の端までスクロールできます。パネルの高さを変更しても表示位置を保ちます。
